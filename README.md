# 🇩🇴 Dominican Republic 2026 — Jostin & Teka

An interactive trip plan for a 6-day trip to the Dominican Republic (June 19–24, 2026):
Santo Domingo's Colonial Zone, a Saturday escape, Bonyé Sunday, and the north coast
(choose Puerto Plata + Cabarete, or Samaná + Los Haitises).

Includes a day-by-day itinerary, experiences filterable by interest (parties, local life,
water sports & cenotes, food, art, history), dinner picks, a "learn Spanish" flashcard
section, and practical info.

**Live site:** https://JKitmang.github.io/dr-2026-trip/

Single static `index.html` — no build step. Open it locally or via GitHub Pages.
